# Financial Calculator Suite

A comprehensive, interactive web application built with React, providing a suite of financial calculators to help users make smarter investment decisions. The application features a modern, responsive UI with glassmorphism elements and real-time complex financial computations.

## Features

* **Multi-Calculator Interface:** Seamlessly switch between different financial tools including SIP, SWP, Step Up SIP, Step Up SWP, Lump Sum, and EMI calculators using a dynamic tab-based routing system.
* **Advanced Financial Logic:** Accurate mathematical models that calculate Future Value, Total Invested Amount, and Returns.
* **Real-World Adjustments:** Built-in toggles to apply Inflation adjustments (Real Purchasing Power) and Capital Gains Tax (12.5%) to the final calculations.
* **Dynamic Rendering:** Smart conditional UI that displays contextual placeholders before calculation and elegant glassmorphism result cards afterward.
* **Modern UI/UX:** Styled entirely with `styled-components`, featuring custom range sliders, smooth state transitions, and a clean layout.

## Tech Stack

* **Frontend:** React.js
* **Styling:** `styled-components` (CSS-in-JS)
* **Architecture:** Component-based architecture with lifted state management and isolated utility functions for mathematical logic.
